# Student Attendance Management System

## Requirements
1. Implement `count_number_of_days_using_dates()` to count unique attendance dates.
2. Implement `find_most_absent_student()` to find the student with the most absent days.
3. Add a `main()` function to display results.

## Functionality Included
- Count number of unique attendance days.
- Find the student with the most absences.
- Show absences for all students.
- List students absent on a given date (user input).
- Show attendance percentage per student.

## Description
This program manages student attendance data,
demonstrates usage of Python built-in collections,
and uses dataclasses for clean data modeling.

Features:
1. Count unique attendance days
2. Find student with most absent days
3. Show all students' absences
4. List students absent on a specific date
5. Show attendance percentage per student
6. Exit

Data is hardcoded but easily extensible to CSV/JSON input.
